# Tage

Minimalistischer Wochenplaner als installierbare Web-App (PWA) für Desktop und Android.

- Wochenansicht mit linierten Spalten, „Irgendwann“-Liste für Aufgaben ohne Datum
- Drag & Drop (Maus und Touch, am Handy per langem Drücken)
- Wiederkehrende Aufgaben (täglich, werktags, wöchentlich, alle 2 Wochen, monatlich, jährlich)
- Unteraufgaben, Notizen, Farbmarkierungen
- Hell/Dunkel/Auto, sechs Akzentfarben
- Offline-fähig, Daten lokal; Backup als JSON

Kein Build-Schritt: reines HTML, CSS und JavaScript (ES-Module).

## Lokal starten

```powershell
.\serve.ps1
```

Dann http://localhost:5173 öffnen. Tastatur: ← → wechselt die Woche, T springt zu heute.
